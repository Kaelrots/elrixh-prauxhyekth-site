구원 계열 상세 설정

구원

위기에 처한 대상을 구호·회복하고, 구속과 오염에서 해방하며, 생존을 보호하는 계열이다. 사랑 계열의 생명 회복과는 별도의 창시 계열이다.

분류
특수 계열(창시형)
에너지
마력 구조를 기반으로 한다. 기법별 공급원과 회수량은 정하지 않았다.
습득 경로
창시자 셰일류츠에게 직접 훈련·전수받는 것이 기본 경로다.
기원
셰일류츠가 창시했다.
분기
구호·회복, 해방·정화, 생존·보호
경계
완전히 사망했거나 영혼이 소멸한 대상을 되살리지 않는다. 소생과 부활의 구별은 영혼·환생 정본을 따른다.

아픔의 문턱에서

생존한 단일 대상의 생체기능 회복과 생명력 운용 안정을 보조.

작동원리
살아 있는 대상의 생체 상태를 읽고 회복 지원을 대상이 받아들일 수 있는 경로로 흘려 넣는다.
습득 조건
생체 상태 판별과 지원 수용 경로 확인을 창시자 아래에서 실습한다. (필요 역량: 살아 있는 대상의 생체 상태·지원 수용 경로를 판별하는 역량)
사용 조건
생존한 단일 대상과 실제 회복 지원의 공급·접속
주요 효과
생존한 단일 대상의 생체기능 회복을 돕고 생명력 운용을 안정시킨다. 사망 후 부활·영혼 복원·상태 해제는 하지 않는다.
유지 조건
해당 없음. 지원하는 동안 대상과 접속을 유지한다.
운용 부담
비용 낮음 — 지원할 만큼의 공급 부하 보통 — 생체 상태 판별 위험 낮음 — 불일치 시 효과 감소 실패 낮음 — 지원이 들지 않을 뿐 후유 낮음 — 없음 회복 낮음 — 곧바로 다시 쓸 수 있음
경계
상태 해제·완전 사망 후 부활·영혼 복원과 구별한다.

상처의 끝에서

국소 상처의 지혈·조직 연결과 회복 가능한 조직 재구성을 보조.

작동원리
상처의 출혈·조직·오염을 판별해 지혈하고, 남아 있는 조직과 정보를 기반으로 연결·재구성한다.
습득 조건
상처 판별과 지혈·조직 연결 실습을 거친다. 아픔의 문턱에서의 선행 습득은 필요 없다. (필요 역량: 상처의 출혈·조직·오염과 복구 가능한 구조를 판별하는 역량)
사용 조건
국소 손상 범위와 회복 가능한 조직·재료/정보의 실제 기반
주요 효과
국소 상처를 지혈하고 회복 가능한 조직을 이어 붙인다. 잃은 조직이나 정보를 무에서 만들지 않는다.
유지 조건
해당 없음. 큰 상처는 여러 번 나눠 처치한다.
운용 부담
비용 낮음 — 국소 처치 소모 부하 보통 — 조직 판별 위험 보통 — 잘못 연결 시 재손상 실패 보통 — 오염이 남으면 회복 지연 후유 낮음 — 없음 회복 낮음 — 곧바로 다시 쓸 수 있음
경계
S01의 필수 상위 단계나 잃은 조직/정보의 무중생성으로 보지 않는다.

숨결을 잇는 손

호흡과 순환이 멎어 가는 대상의 숨과 맥을 이어 붙잡는 응급 지원. 치료가 닿을 때까지 버틸 시간을 번다.

작동원리
대상의 호흡·순환 리듬을 읽어 시전자의 생명력으로 박자를 보태 끊기지 않게 잇는다.
습득 조건
창시자 아래 응급 실습에서 호흡·순환 판별과 보조를 익힌다. (필요 역량: 호흡·순환 상태를 판별하고 보조하는 응급 역량)
사용 조건
아직 살아 있는 단일 대상과 손이 닿는 거리
주요 효과
대상의 숨과 맥이 끊기지 않게 붙들어 치료가 닿을 시간을 번다. 원인 손상은 고치지 않는다.
유지 조건
손을 대고 있는 동안만 유지된다. 손을 떼면 대상의 상태대로 돌아간다.
운용 부담
비용 낮음 — 소량의 생명력 부하 보통 — 리듬 유지 집중 위험 낮음 — 부작용 적음 실패 보통 — 손상이 크면 못 붙듦 후유 낮음 — 없음 회복 낮음 — 곧바로 다시 쓸 수 있음
경계
멎은 지 오래된 대상이나 사망한 대상을 되살리지 않는다.
숨결을 잇는 손 카드로 돌아가기

다시 일어서는 자

남아 있는 회로·운동기능을 조율해 제한된 활동 복귀를 지원.

작동원리
남아 있는 회로와 운동기능의 부담을 재조율해 허용 가능한 범위 안에서 활동을 이어 가게 한다.
습득 조건
회복 후 잔존 기능과 허용 부하를 판단하는 수련을 거친다. 특정 치료 기법의 선행 습득은 필요 없다. (필요 역량: 회복 후 남은 기능과 허용 가능한 활동 부하를 판단하는 역량)
사용 조건
손상 원인이 통제되고 활동 가능한 기능이 남은 대상
주요 효과
손상 원인이 통제된 대상이 제한된 범위에서 다시 움직이고 싸울 수 있게 한다. 새 능력·각성·부활은 주지 않는다.
유지 조건
지원하는 동안 대상의 부하를 계속 살펴야 한다. 한계를 넘으면 활동을 줄이거나 지원을 멈춘다.
운용 부담
비용 보통 — 지속 조율 소모 부하 보통 — 부하 감시 위험 높음 — 무리 시 재손상 실패 보통 — 기능 부족 시 복귀 실패 후유 보통 — 대상 탈진 회복 보통 — 대상 휴식 필요
경계
S02 등 특정 치료 기법의 선행 시전/습득은 필수가 아니다. 새 능력/각성/부활을 부여하지 않는다.
다시 일어서는 자 카드로 돌아가기

피로의 끝에서

탈진하거나 마력이 바닥난 대상이 스스로 회복하는 흐름을 되살려 준다. 기운을 대신 채워 주는 것이 아니라 회복 경로를 다시 연다.

작동원리
막히거나 멎은 생체·마나회로의 회복 흐름을 짚어 다시 돌기 시작하게 한다.
습득 조건
아픔의 문턱에서 수준의 생체 판별을 다룬 뒤 회로 회복 실습을 거친다. 선행 습득은 필수가 아니다. (필요 역량: 탈진과 마나회로 고갈 상태를 판별하는 역량)
사용 조건
탈진·마나 고갈 상태의 살아 있는 대상
주요 효과
탈진한 대상이 평소보다 빨리 기운과 마력을 되찾는다. 무리한 대상에게 곧바로 전투력을 돌려주지는 않는다.
유지 조건
해당 없음.
운용 부담
비용 보통 — 흐름 재개 소모 부하 보통 — 회로 판별 위험 낮음 — 부작용 적음 실패 보통 — 손상된 회로는 더딤 후유 낮음 — 없음 회복 낮음 — 곧바로 다시 쓸 수 있음
경계
체력·마력을 무에서 채우지 않는다. 회복 속도를 돕는 데 그친다.
피로의 끝에서 카드로 돌아가기

무너짐의 문턱에서

생체기능·마나회로의 연쇄 부전을 분리·우회해 붕괴를 늦춤.

작동원리
연쇄적으로 무너지는 생체기능과 마나회로를 분리하고 우회 경로를 세워 붕괴의 전파를 늦춘다.
습득 조건
생체·회로 연쇄 부전의 판별과 우회 부담 판단을 고급 실습으로 익힌다. (필요 역량: 생체기능·마나회로의 연쇄 부전과 우회 부담을 판별하는 역량)
사용 조건
진행 중인 연쇄 기능 저하와 유지 가능한 기능 경로
주요 효과
다발성 기능 부전이 진행 중인 대상의 붕괴를 늦춰 치료할 시간을 번다. 완치가 아니며 광역 위기는 죽음의 문턱에서의 몫이다.
유지 조건
우회 경로를 외부에서 지지하는 동안만 유지된다. 공급이 끊기면 붕괴가 다시 진행된다.
운용 부담
비용 높음 — 우회 지지 소모 부하 높음 — 연쇄 경로 동시 관리 위험 높음 — 우회 부담이 대상에게 감 실패 보통 — 진행이 빠르면 못 따라감 후유 보통 — 시전자 탈진 회복 높음 — 긴 휴식 필요
경계
안정화는 완치가 아니다. S12와 대상/위기 범위를 구분한다.
무너짐의 문턱에서 카드로 돌아가기

생명을 나누는 손

시전자 자신의 생명력 일부를 떼어 위중한 대상에게 나눠 준다. 다른 방법이 없을 때 쓰는 자기희생 기법이다.

작동원리
시전자 생명력의 흐름을 대상의 생명력 운용에 맞춰 조율한 뒤 직접 이어 넘긴다.
습득 조건
생명력 판별과 이식 조율을 창시자에게 직접 지도받는다. 자기 한계 판단을 반드시 함께 익힌다. (필요 역량: 자기 생명력을 떼어 대상 체계에 맞춰 넘기는 역량)
사용 조건
살아 있는 위중한 단일 대상, 시전자에게 나눌 생명력이 남아 있을 것
주요 효과
대상이 시전자에게서 받은 생명력만큼 버틸 힘을 얻는다. 시전자는 나눈 만큼 약해진다.
유지 조건
해당 없음.
운용 부담
비용 극심 — 자기 생명력 소모 부하 보통 — 체계 조율 위험 높음 — 과다 분여 시 시전자 위험 실패 보통 — 체계 불일치 시 손실 후유 높음 — 시전자 쇠약 회복 높음 — 생명력 회복에 긴 시간
경계
생명력이며 영혼·수명을 넘기지 않는다. 사망한 대상에는 통하지 않는다.
생명을 나누는 손 카드로 돌아가기

고통의 문턱에서

유해 상태의 유지 구조를 해제하고 같은 경로의 재유입을 완충.

작동원리
유해 상태를 유지시키는 구조를 찾아 풀고, 같은 경로로 다시 들어오는 작용을 한동안 완충한다.
습득 조건
유해 작용의 유지 경로와 대상 자기기반을 구분하는 수련을 거친다. (필요 역량: 유해 작용의 유지 경로와 대상 자기기반을 식별하는 역량)
사용 조건
해제할 수 있는 유해 구조와 같은 경로의 재유입 정보
주요 효과
독·저주 잔재 같은 유해 상태를 해제하고 같은 경로의 재유입을 줄인다. 손상 복원과 다르며 모든 원인에 대한 면역은 아니다.
유지 조건
재유입 완충은 짧게 유지되며 시전자가 접속을 거두면 끝난다.
운용 부담
비용 보통 — 해제·완충 소모 부하 보통 — 유지 경로 식별 위험 보통 — 자기기반 오판 시 부작용 실패 보통 — 강한 구조는 재발 후유 낮음 — 없음 회복 낮음 — 곧바로 다시 쓸 수 있음
경계
손상 복원과 구별한다. 모든 상태/모든 원인에 대한 면역이 아니다.

오염의 끝에서

물이나 땅, 공기, 물품에 스민 유해한 오염을 국소적으로 씻어 낸다. 피난과 구호가 이뤄질 자리를 먼저 깨끗하게 한다.

작동원리
오염 물질과 바탕 물질의 결합을 풀어 유해 성분을 분리·흩어 낸다.
습득 조건
고통의 문턱에서와 같은 해제 감각을 물질·환경에 적용하는 실습으로 익힌다. (필요 역량: 물질·환경 오염의 종류와 범위를 판별하는 역량)
사용 조건
국소 범위의 오염된 물질·환경과 오염 원인 판별
주요 효과
마실 물, 디딜 땅, 숨쉴 공기를 국소적으로 안전하게 만든다.
유지 조건
해당 없음. 오염원이 남아 있으면 다시 오염된다.
운용 부담
비용 낮음 — 국소 정화 부하 낮음 — 단순 판별 위험 낮음 — 부작용 적음 실패 보통 — 강한 오염은 일부만 후유 낮음 — 없음 회복 낮음 — 곧바로 다시 쓸 수 있음
경계
오염원 자체를 없애지 않으면 다시 오염된다. 넓은 지역 정화는 아니다.

속박의 끝에서

외부 물리·마도 구속의 실제 접속부를 풀거나 약화.

작동원리
외부 물리·마도 구속의 실제 접속부를 찾아 풀거나 약하게 만든다.
습득 조건

퇴각 중인 아군과 후미를 지킬 자리, 시전자의 버틸 여력
주요 효과
적의 공격과 추격이 시전자에게 몰려 퇴각하는 아군이 빠져나갈 시간을 번다.
유지 조건
시전자가 버티는 동안 유지된다. 아군이 모두 빠져나가거나 시전자가 쓰러지면 끝난다.
운용 부담
비용 높음 — 버티는 소모 부하 높음 — 위협 유인·흡수 위험 극심 — 시전자가 집중 공격받음 실패 높음 — 포위되면 무너짐 후유 높음 — 깊은 부상 가능 회복 높음 — 긴 휴식 필요
경계
시전자를 불사로 만들지 않는다. 시전자 생존도 보장하지 않는다.

죽음의 문턱에서

죽음으로 넘어가기 직전의 대상을 광역적으로 안정화하고 추가 치명상을 억제한다. 이미 완전히 사망한 존재를 부활시키는 기법은 아니다.

작동원리
넓은 범위에서 아직 죽지 않은 위기 대상을 판별해 생명 유지 경계를 동시에 받치고 추가 치명상을 억제한다.
습득 조건
앞선 구원 기법 전부의 습득은 조건이 아니다. 죽음 직전 판별과 광역 안정화를 창시자에게 직접 지도받아야 한다. (필요 역량: 죽음 직전의 판별·광역 안정화·추가 치명상 억제를 통제할 역량)
사용 조건
아직 완전 사망하지 않은 위기 대상과 실제 개입 기반
주요 효과
죽음 직전의 다수 대상을 한꺼번에 안정시키고 추가 치명상을 억제한다. 이미 완전히 사망한 존재는 되살리지 못한다.
유지 조건
억제는 시전자가 버티는 동안만 유지된다. 대상 수가 늘수록 유지 시간이 짧아진다.
운용 부담
비용 극심 — 광역 안정화 소모 부하 극심 — 다수 판별·억제 위험 높음 — 과부하 시 시전자 위험 실패 높음 — 한계를 넘으면 일부 누락 후유 높음 — 깊은 탈진 회복 극심 — 오랜 회복 필요
경계
최고위 표기는 기존 원문을 유지하되 S01~S11 전부 습득/시전 조건이나 부활로 바꾸지 않는다.

분리 채널 정화·완충형

제거와 같은 경로 재유입 완충의 유지 회로를 분리해 운용

보존한 핵심
식별 가능한 유해 상태 유지 구조의 해제와 동일 경로 완충
작동원리
유해 구조를 푸는 회로와 같은 경로의 재유입을 막는 완충 회로를 둘로 나눠 따로 유지한다.
사용 조건
고통의 문턱에서를 쓸 수 있고, 해제와 완충을 따로 붙들 여력이 있을 것.
습득 조건
고통의 문턱에서를 숙련한 뒤 회로 분리 운용을 창시자에게 지도받는다.
유지 조건
해제 회로는 해제가 끝나면 닫고, 완충 회로는 따로 유지한다. 완충 회로를 거두는 시점을 시전자가 정할 수 있다.
실패
회로를 나누다 해제가 덜 끝나면 유해 구조가 다시 붙는다. 완충 회로가 끊기면 재유입이 즉시 다시 일어난다. 단순히 더 오래 지속하는 것은 Variant가 아니라 숙련 차이다.
운용 부담
비용 보통 — 두 회로 유지 부하 높음 — 회로 분리 제어 위험 보통 — 해제 미완 시 재부착 실패 보통 — 완충 단절 후유 낮음 — 없음 회복 보통 — 재정비 시간
분리 채널 정화·완충형 카드로 돌아가기

공동 이동경계형

대상별 부착 보호층과 구별되는 공유 경계 접속/추적 구조로 집단을 따라감

보존한 핵심
실제 연결된 대상과 함께 움직이는 위협 감쇠 보호층
작동원리
대상마다 보호층을 붙이는 대신 집단 전체를 감싸는 공유 경계를 세우고, 경계의 모양을 집단의 움직임에 맞춰 추적한다.
사용 조건
구원의 장막을 쓸 수 있고, 보호할 집단이 서로 크게 흩어지지 않을 것.
습득 조건
구원의 장막을 숙련한 뒤 공유 경계 추적을 수련한다.
유지 조건
집단이 움직이는 동안 경계 모양을 계속 고친다. 누군가 경계 밖으로 벗어나면 다시 들어오기 전까지 보호가 빠진다.
실패
집단이 갑자기 갈라지면 경계가 늘어나다 끊긴다. 끊긴 뒤 다시 잇는 데 부하가 든다. 인원수 차이만으로는 Variant가 되지 않는다.
운용 부담
비용 보통 — 공유 경계 유지 부하 높음 — 모양 추적 위험 보통 — 이탈자 무방비 실패 보통 — 집단 분산 후유 낮음 — 가벼운 피로 회복 보통 — 재접속 부하
