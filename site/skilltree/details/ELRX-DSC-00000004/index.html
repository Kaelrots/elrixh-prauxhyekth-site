신성

신성력을 발현하고, 대상과 무기에 부여하며, 보호하는 신성 계통의 기초 계열이다.

분류
신성 계열
에너지
신성력. 공급과 접속, 정형을 구분한다.
습득 경로
교육·수련을 기본 경로로 하고 계열 성격에 따른 추가 조건을 붙인다. 자력 터득·모방은 예외 경로로 허용한다. 수련과 함께 해당 신격 또는 신성원리와의 연결(신앙 공명)이 있어야 습득·발현된다.
분기
발현, 부여, 수호
경계
신성 신분이나 계열 이름만으로 직접 권능, 법적 권한, 빛 속성을 부여하지 않는다.

신성 발현

신성력을 감지 가능한 빛과 압력의 형태로 끌어내는 신성 계열의 기본기다. 다른 신성 기법은 모두 이 발현에서 출발한다.

작동원리
연결된 신격·신성원리와의 공명을 통해 신성력을 몸 밖으로 끌어내 형태를 준다.
습득 조건
신앙 공명이 처음 성립한 상태에서 입문 수련으로 익힌다.
사용 조건
연결 신격과의 공명이 유지되고 있을 것.
주요 효과
주변을 밝히는 신성광과 약한 압력을 낸다. 부정·저주의 잔재가 있으면 반응해 위치를 드러낸다.
유지 조건
해당 없음. 집중하는 동안 짧게 이어 갈 수 있다.
운용 부담
비용 낮음 — 소량의 신성력 부하 낮음 — 기초 집중 위험 낮음 — 부작용 거의 없음 실패 낮음 — 발현이 흩어질 뿐 후유 낮음 — 없음 회복 낮음 — 곧바로 다시 쓸 수 있음

신의 격노

응집한 신성력을 단일 대상에게 쏟아낸다. 적중한 대상에게는 한동안 신성력이 남아 추가 피해를 준다.

작동원리
응집한 신성력을 한 대상에 집중해 쏟아내고 그 잔재를 대상 안에 남긴다.
습득 조건
신성력 응집 수련을 거친 뒤 익힌다.
사용 조건
공명이 유지되고 시야 안에 단일 대상이 있을 것.
주요 효과
단일 대상에 신성 피해를 주고, 남은 신성력이 한동안 추가 피해를 낸다. 정화로 잔재를 씻어 낼 수 있다.
유지 조건
해당 없음. 잔재는 시간이 지나면 사라진다.
운용 부담
비용 보통 — 응집 소모 부하 보통 — 집중 위험 낮음 — 단일 대상 실패 보통 — 빗나가면 흩어짐 후유 낮음 — 없음 회복 보통 — 재응집 시간

정화의 빛

부정·저주의 잔재에 반응하는 약한 정화광을 비춘다. 본격적인 정화는 자애 계열이 맡는다.

작동원리
신성 발현의 빛을 부정한 힘의 흔적에 맞춰 조율해 잔재를 흩는다.
습득 조건
신성 발현을 안정적으로 다룰 것.
사용 조건
정화할 대상이나 장소가 빛이 닿는 범위에 있을 것.
주요 효과
약한 저주 잔재와 오염 흔적을 흩는다. 강한 저주는 위치와 세기만 드러낸다.
유지 조건
해당 없음.
운용 부담
비용 보통 — 조율에 신성력이 듦 부하 낮음 — 짧은 집중 위험 낮음 — 부작용 적음 실패 보통 — 강한 저주에는 효과가 미미함 후유 낮음 — 없음 회복 낮음 — 곧 다시 쓸 수 있음

성광 개방

오래 축적한 신성력을 넓은 범위에 한 번에 방출한다.

작동원리
쌓아 둔 신성력을 공명의 한계까지 끌어올려 일시에 개방한다.
습득 조건
신성 계열 고등 기법을 두루 익힌 숙련과 깊은 신앙 공명.
사용 조건
방출할 만큼 신성력을 축적해 둘 것. 연결 신격의 뜻에 반하지 않을 것.
주요 효과
넓은 범위의 부정한 존재와 적대 대상에게 신성광이 쏟아진다. 피아 식별은 시전자의 의지에 달려 있어 혼전에서는 아군도 휘말릴 수 있다.
유지 조건
해당 없음.
운용 부담
비용 극심 — 축적분을 한꺼번에 소모 부하 높음 — 공명 한계까지 끌어올림 위험 높음 — 아군이 휘말릴 수 있음 실패 높음 — 개방이 끊기면 신성력이 역류 후유 높음 — 탈진 회복 극심 — 축적을 다시 쌓기까지 오래 걸림

신성한 힘

신성력을 끌어내 자신의 무기나 단일 대상에 부여한다. 부여된 타격은 물리·마법 방호로 쉽게 줄어들지 않는 신성 피해를 더한다.

작동원리
신성력을 무기나 대상의 표면에 입혀 접촉할 때 함께 흘러들게 한다.
습득 조건
신성 발현을 다룰 수 있게 된 뒤 부여 수련으로 익힌다.
사용 조건
연결 신격과 공명이 유지되고, 부여할 무기나 대상에 닿을 수 있을 것.
주요 효과
부여된 무기·대상의 타격에 신성 피해가 더해진다. 물리·마법 방호로 쉽게 줄지 않지만 신성 방호에는 줄어든다.
유지 조건
부여한 신성력이 남아 있는 동안 유지된다. 공명이 끊기면 곧 흩어진다.
운용 부담
비용 낮음 — 소량의 신성력 부하 낮음 — 부여 뒤 신경 쓸 것 적음 위험 낮음 — 부작용 적음 실패 낮음 — 부여가 흩어질 뿐 후유 낮음 — 없음 회복 낮음 — 곧바로 다시 부여

축복의 손

접촉한 아군 한 명에게 짧은 신성 보호를 입힌다.

작동원리
발현한 신성력을 접촉면을 통해 대상의 몸에 얇은 막으로 입힌다.
습득 조건
신성력에 형태를 주는 기초 수련.
사용 조건
대상과 직접 접촉할 것. 대상이 신성력을 거부하지 않을 것.
주요 효과
짧은 동안 대상이 받는 피해 일부를 덜어 준다. 강한 일격 한 번에 막이 깨진다.
유지 조건
해당 없음.
운용 부담
비용 낮음 — 소량의 신성력 부하 낮음 — 짧은 집중 위험 낮음 — 부작용 거의 없음 실패 보통 — 대상이 움직이면 막이 고르게 입혀지지 않음 후유 낮음 — 없음 회복 낮음 — 곧바로 다시 쓸 수 있음

신성 공명

주변의 성물·성지·신성원과 동조해 신성력 출력을 안정시킨다.

작동원리
연결 신격과의 공명을 주변 신성원까지 넓혀 신성력 흐름의 진폭을 고르게 한다.
습득 조건
깊고 안정된 신앙 공명. 성지·성물 곁에서의 오랜 수련.
사용 조건
동조할 신성원(성물·성지·신앙 공동체 등)이 곁에 있을 것.
주요 효과
유지하는 동안 신성 기법의 출력이 안정되고 실패가 줄어든다. 신성원이 없으면 효과가 거의 없다.
유지 조건
동조 상태에 집중해야 한다. 신성원과 멀어지거나 공명이 흐트러지면 풀린다.
운용 부담
비용 보통 — 동조 유지 부하 높음 — 오래 동조하는 집중 위험 보통 — 이질적인 신성원과 부딪힐 수 있음 실패 보통 — 공명이 흐트러짐 후유 보통 — 풀린 뒤 피로 회복 보통 — 다시 동조하려면 쉬어야 함
신성 공명 카드로 돌아가기

수호의 빛

날아드는 공격 앞에 순간적으로 신성 막을 세운다.

작동원리
위협을 감지한 순간 신성 발현을 한 점에 응축해 막으로 펼친다.
습득 조건
신성 발현을 빠르게 끌어내는 수련.
사용 조건
공격을 인지할 수 있을 것. 시전자 자신이나 바로 곁의 아군에게만.
주요 효과
공격 한 번의 위력을 크게 줄인다. 막은 곧바로 사라진다.
유지 조건
해당 없음.
운용 부담
비용 낮음 — 순간 소모 부하 보통 — 반사적 집중 위험 낮음 — 부작용 적음 실패 보통 — 늦으면 효과 없음 후유 낮음 — 없음 회복 낮음 — 곧 다시 쓸 수 있음

신성 방벽

정한 위치에 신성력 차단면을 세운다. 자애의 성역과 달리 국소적이고 짧게 유지되는 방어다.

작동원리
신성력을 평면 구조로 고정해 통과하려는 공격과 부정한 힘을 막는다.
습득 조건
신성력을 일정한 형태로 고정하는 수련.
사용 조건
세울 위치를 볼 수 있고 시전자가 가까이 있을 것.
주요 효과
차단면이 버티는 동안 정면의 공격을 막는다. 부정한 존재에게는 더 강하게 작용한다.
유지 조건
시전자가 신성력을 계속 공급하는 동안 유지된다. 공급이 끊기거나 버틸 수 있는 이상의 충격을 받으면 무너진다.
운용 부담
비용 보통 — 유지하는 동안 계속 공급 부하 보통 — 유지에 집중 위험 낮음 — 부작용 적음 실패 보통 — 과한 충격에 붕괴 후유 낮음 — 없음 회복 보통 — 다시 세우려면 잠시 쉬어야 함

신의 성지

시전자 주변에 일정 시간 지속되는 성지를 발현한다. 성지 안의 아군이 받는 피해 일부를 시전자가 나눠 받고, 아군의 공격에는 신성력이 실린다.

작동원리
시전자를 중심으로 신성력이 고인 영역을 세우고, 영역 안 아군과 신성력의 연결을 맺는다.
습득 조건
성역 형성 수련과 깊은 신앙 공명이 필요하다.
사용 조건
공명이 유지되고 시전자가 성지 중심에 머무를 것.
주요 효과
성지 안 아군이 받는 피해 일부를 시전자가 나눠 받고, 아군 공격에 신성 피해가 더해진다.
유지 조건
정해진 시간 유지된다. 시전자가 성지를 벗어나거나 쓰러지면 사라진다.
운용 부담
비용 높음 — 영역 유지 부하 보통 — 연결 유지 위험 높음 — 대신 받은 피해 누적 실패 보통 — 과부하 시 해체 후유 보통 — 피해 후유 회복 높음 — 재형성 시간

국소적이고 짧게 유지되는 신성력 차단면
작동원리

사용 조건

습득 조건

유지 조건
