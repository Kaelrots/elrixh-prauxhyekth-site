마법

마법 계통의 기초 계열이다. 마법구조의 해석, 기초 술식, 마력 운용을 다룬다. 원소 단계는 원소마법 전문 계열로 옮겨졌다.

분류
마도 계열
에너지
마력. 마나·환경 마력·저장체 등 구체적인 공급은 기법별로 기록한다.
습득 경로
교육·수련을 기본 경로로 하고 계열 성격에 따른 추가 조건을 붙인다. 자력 터득·모방은 예외 경로로 허용한다.
분기
해석, 기초술식, 마력운용
경계
영창과 연구를 모든 기법의 필수 조건으로 정하지 않는다.

마력 감지

주변 마력의 흐름과 밀도를 감지한다.

작동원리
자기 마력을 얇게 펼쳐 외부 마력과 부딪히는 간섭을 읽는다.
습득 조건
마력을 의식적으로 다루는 기초 수련.
사용 조건
감지할 범위에 집중할 수 있을 것.
주요 효과
술식·마력 생물·마력 잔재의 위치와 세기를 대략 알아챈다. 정밀한 구조 판독은 해석 분기의 상위 기법이 맡는다.
유지 조건
상시. 집중을 높이면 더 멀리, 더 자세히 감지한다.
운용 부담
비용 낮음 — 미량의 마력 부하 보통 — 넓히면 집중이 필요 위험 낮음 — 부작용 거의 없음 실패 보통 — 강한 마력장에서는 흐려짐 후유 낮음 — 없음 회복 낮음 — 상시 유지
마력 감지 카드로 돌아가기

술식 해제

구조가 파악된 다른 술식을 분해한다.

작동원리
술식의 결합 지점을 찾아 마력으로 풀어낸다.
습득 조건
마력 감지와 술식 구조에 대한 이해.
사용 조건
대상 술식의 구조를 읽을 수 있을 것.
주요 효과
단순·중급 마력 술식을 무력화한다. 신성·계약·혈통에 기반한 힘에는 통하지 않는다.
유지 조건
해당 없음.
운용 부담
비용 보통 — 분해에 쓰는 마력 부하 보통 — 구조 판독 위험 보통 — 잘못 풀면 술식이 폭주할 수 있음 실패 보통 — 복잡한 술식은 실패 후유 낮음 — 없음 회복 보통 — 연달아 쓰면 지침
술식 해제 카드로 돌아가기

술식 반전

들어오는 단순 술식을 같은 구조로 맞받아 지운다. 이퀄리브리엄의 반사와 달리 되돌리지 않는다.

작동원리
들어오는 술식의 구조를 순간적으로 읽어 반대 구조를 맞붙인다.
습득 조건
술식 해제의 숙련과 빠른 판독.
사용 조건
술식을 알아챌 시간과 그에 맞먹는 마력.
주요 효과
단순 마력 술식 하나를 무효로 만든다. 복잡한 술식은 일부만 약해지고, 신성·계약·혈통 기반의 힘에는 통하지 않는다.
유지 조건
해당 없음.
운용 부담
비용 보통 — 맞받는 만큼의 마력 부하 높음 — 순간 판독 위험 보통 — 판독이 틀리면 정면으로 맞음 실패 높음 — 늦거나 틀리기 쉬움 후유 낮음 — 없음 회복 보통 — 연달아 쓰기 어려움
술식 반전 카드로 돌아가기

마력탄

순수 마력을 탄으로 만들어 투사한다.

작동원리
마력을 응축해 단순한 탄 구조로 묶고 방향을 준다.
습득 조건
마력 응축 기초 수련.
사용 조건
가용 마력과 겨눌 대상이 있을 것.
주요 효과
속성 없는 마력 충격을 준다. 마력 방호에 쉽게 상쇄된다.
유지 조건
해당 없음.
운용 부담
비용 낮음 — 소량의 마력 부하 낮음 — 단순 구조 위험 낮음 — 부작용 거의 없음 실패 낮음 — 빗나갈 뿐 후유 낮음 — 없음 회복 낮음 — 곧 다시 쓸 수 있음
마력탄 카드로 돌아가기

마력 방벽

단순한 마력 차단면을 세운다. 방호마법 전문계열의 하위 기초형이다.

작동원리
마력을 평면으로 펼쳐 들어오는 힘을 흩는다.
습득 조건
마력 응축 기초 수련.
사용 조건
가용 마력이 있을 것.
주요 효과
가벼운 공격과 단순 술식을 막는다. 강한 공격이나 정교한 술식에는 쉽게 깨진다.
유지 조건
짧게 유지되며 마력 공급이 끊기면 사라진다.
운용 부담
비용 낮음 — 소량의 마력 부하 낮음 — 짧은 유지 위험 낮음 — 부작용 거의 없음 실패 보통 — 강한 공격에 깨짐 후유 낮음 — 없음 회복 낮음 — 곧 다시 쓸 수 있음
마력 방벽 카드로 돌아가기

다중 영창

둘 이상의 단순 술식을 동시에 짠다.

작동원리
주의를 나눠 여러 술식 구조를 병렬로 엮는다.
습득 조건
단순 술식의 숙달.
사용 조건
충분한 마력과 집중.
주요 효과
마력탄·마력 방벽 같은 단순 술식을 동시에 펼친다.
유지 조건
해당 없음.
운용 부담
비용 보통 — 술식 수만큼 소모 부하 높음 — 주의 분할 위험 보통 — 구조가 엉킬 수 있음 실패 보통 — 한쪽이 무너짐 후유 보통 — 두통·피로 회복 보통 — 쉬어야 다시 쓸 수 있음
다중 영창 카드로 돌아가기

술식 고정

술식을 미리 걸어 두었다가 조건이 맞으면 발동하게 한다.

작동원리
술식 구조를 마력으로 공간이나 물체에 묶어 두고 발동 조건을 건다.
습득 조건
단순 술식을 안정적으로 짜는 능력.
사용 조건
고정할 위치나 물체, 그리고 단순한 발동 조건.
주요 효과
설치한 자리에 조건(접촉·통과·시간 등)이 맞으면 술식이 발동한다.
유지 조건
고정한 마력이 남아 있는 동안 유지된다. 시간이 지나면 흩어지고 해석 기법으로 해제될 수 있다.
운용 부담
비용 보통 — 구조를 묶는 마력 부하 보통 — 조건 설계 위험 보통 — 아군이 조건을 건드릴 수 있음 실패 보통 — 조건 오작동 후유 낮음 — 없음 회복 보통 — 여러 개를 걸면 회복이 늦음
술식 고정 카드로 돌아가기

마력 순환

몸 안의 마력 순환 효율을 높여 소모를 줄인다.

작동원리
마력이 몸을 도는 경로를 정돈해 새어 나가는 양을 줄인다.
습득 조건
오랜 호흡·명상 수련.
사용 조건
상시.
주요 효과
같은 기법을 쓸 때 소모가 줄고 마력 회복이 빨라진다.
유지 조건
상시 유지되지만 큰 부상이나 정신적 혼란에서는 흐트러진다.
운용 부담
비용 낮음 — 소모를 줄이는 기법 부하 낮음 — 몸에 밴 습관 위험 낮음 — 부작용 거의 없음 실패 보통 — 흐트러지면 효율이 돌아옴 후유 낮음 — 없음 회복 낮음 — 상시
마력 순환 카드로 돌아가기

마력 개방

축적한 마력을 한꺼번에 방출한다. 과부하 위험이 크다.

작동원리
마력 순환의 제어를 잠시 풀어 쌓아 둔 마력을 한 번에 쏟아낸다.
습득 조건
마력 순환의 깊은 숙달.
사용 조건
방출할 만큼의 축적 마력.
주요 효과
짧은 시간 술식의 위력과 범위가 크게 늘거나, 순수 마력 폭발을 일으킨다.
유지 조건
해당 없음.
운용 부담
비용 극심 — 축적분을 모두 소모 부하 극심 — 제어를 풀어 둠 위험 극심 — 마나회로 손상 위험 실패 높음 — 제어를 되찾지 못하면 폭주 후유 극심 — 회로 손상 시 오랫동안 마력을 못 씀 회복 극심 — 회복에 오랜 시간
마력 개방 카드로 돌아가기

연쇄 고정형

고정한 술식 하나가 발동하면 그 발동이 다음 고정 술식의 발동 조건이 되도록 잇는다.

보존한 핵심
술식을 미리 걸어 두었다가 조건이 맞으면 발동
작동원리
앞 술식의 발동 신호를 다음 술식의 조건 검출에 묶어 순서대로 터지게 한다.
사용 조건
미리 걸어 둘 술식들과 그만큼의 마력이 있을 것.
습득 조건
술식 고정과 다중 영창을 다룬 뒤 연쇄 결속 수련을 거친다.
유지 조건
걸어 둔 동안 각 술식의 고정을 유지해야 한다.
실패
중간 술식이 해제되거나 불발하면 그 뒤가 모두 멈춘다.
운용 부담
비용 보통 — 여러 술식 고정 부하 높음 — 연쇄 설계 위험 보통 — 오발 연쇄 실패 높음 — 한 고리 끊김 후유 낮음 — 없음 회복 보통 — 다시 걸기
연쇄 고정형 카드로 돌아가기
